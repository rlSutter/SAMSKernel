# SAMS Kernel: the glyph set

256 glyphs of 6 x 8 pixels, generated by `tools/font.py` into the data bank (`gen/font.a99`). Text 80 draws the left six
bits of each pattern byte. ASCII glyphs are five pixels wide in columns 0-4 (column 5 is the gap) with capitals on row 6
and row 7 left for descenders and the underline; box-drawing glyphs use all six columns so that lines join. Run
`examples/diag` to see the whole set on screen (rows 7-14, 32 glyphs a row, the first code of each row at the left).

| Codes | What |
| --- | --- |
| 0-31 | UI glyphs (below) |
| 32-126 | ASCII |
| 127 | the "Latin-1" marker: a box with a dot, for a stored character that has no glyph |
| 128-222 | ASCII 32-126 **underlined**: add 96 to a character's code to underline it |
| 223-255 | more UI glyphs (below); 235-255 are blank |

## Making your own

Copy `kernel/databank.a99` and `tools/font.py` into your application, edit the `UI` and `A` tables in the script (a glyph
is a list of up to eight strings of `#` and `.`), generate `gen/font.a99`, and put your `databank.a99` in the application's
directory: the build looks there first. Keep 256 glyphs at `>E000` and the five 16-word colour schemes at `>E800`.
